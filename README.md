# How Not to Write (moved)

This skill now lives in **[jorshimayor/writing-studio](https://github.com/jorshimayor/writing-studio/tree/main/plugins/how-not-to-write)**, alongside Writing Studio. This repository is archived and no longer updated. Its full history was carried over to the new repo.

Install from the new home:

```
/plugin marketplace add jorshimayor/writing-studio
/plugin install how-not-to-write@writing-studio
```

For claude.ai, download `how-not-to-write.zip` from the [latest Writing Studio release](https://github.com/jorshimayor/writing-studio/releases/latest).
