# How Not to Write (moved)

How Not to Write is now built into **[Writing Studio](https://github.com/jorshimayor/writing-studio)**, the all-in-one writing skill for Web3 technical writers. Its three rules (no "it's not X, it's Y" cadence, no em dashes, no padding) apply to everything Writing Studio writes or edits. This repository is archived and no longer updated.

Install Writing Studio instead:

```
/plugin marketplace add jorshimayor/writing-studio
/plugin install writing-studio@writing-studio
```

For claude.ai, download `writing-studio.zip` from the [latest release](https://github.com/jorshimayor/writing-studio/releases/latest). If you installed How Not to Write separately, remove it so the same rules aren't applied twice.
